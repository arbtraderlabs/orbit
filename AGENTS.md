# ORBIT Agent Instructions

This is a standalone open-source project. Never assume CrashDash context or prior conversations.

Before work: verify git remote, branch, HEAD, working-tree cleanliness and issue scope; read docs/architecture/FRAMEWORK_SPEC.md, docs/operations/IMPLEMENTATION_PLAN.md and the exact issue. Inspect code and tests before editing.

Use isolated feature branches/worktrees; preserve all existing worktrees, untracked files and local edits. No secret access, GitHub permission changes, merges, deployments, destructive cleanup or cross-repository actions without explicit authorisation. Execute bounded authorised tasks and test changes; report exact evidence. A generated issue is not an admitted job, and DONE is not ACCEPTED.

Phase 1 is bootstrap-only. Do not claim a functioning autonomous worker or Codex review gate until those phases pass independent acceptance.
